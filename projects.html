    Spatial Awareness for the Visually Impaired (S.A.V.I.)

    We're developing a wearable device to help people with visual impairments better navigate their surroundings. It uses a camera to recognize objects and obstacles and provides audio feedback through a DFPlayer to help guide the user.

    I worked on the computer vision side of the project. I collected and labeled over 3,100 images and used them to train a custom YOLO model in PyTorch. I also worked on getting the model running on an edge AI module so it could recognize objects in real time.

    Senior Design: PyTorch · Ultralytics YOLO · Roboflow · Edge AI · Python

  • Summer 2026

    Project name

    DigiCam is a small standalone digital camera I built using an ESP32-CAM. It captures pictures and short videos and saves them to a microSD card. It also creates its own Wi-Fi network so the live feed can be viewed from a computer. It also has two physical buttons for taking pictures and recording videos along with remote control.

    I designed and built the entire system, including the PCB, firmware, and 3D-printed enclosure. One of the bigger challenges was getting the camera to start reliably because it kept running into power issues during initialization. I added LED blink codes to help figure out where it was failing and used a bench power supply to determine the problem.

    Junior Design: ESP32-CAM · C++ · Embedded Systems · Wi-Fi · 3D Printing

  • Summer 2026

    Bop-It

    For this project, we built our own version of Bop-It using an Arduino Nano. Players respond to different commands, and the game uses an accelerometer, microphone, and infrared sensor to detect their actions. We also included a 7-segment display and DFPlayer Mini for the score and audio.

    I worked on the game logic and firmware, testing each sensor and making sure it responded the way it should. I also tested the code in SimulIDE before we had the hardware and helped troubleshoot problems when we put everything together on the PCB.

    Junior Design: Altium · Arduino · I2C ·Embedded C · SimulIDE

    Spring 2026

    Autonomous Formula E Racing Robot

    For this project, I worked with two other students to build an autonomous Formula E racing robot. There were two separate challenges: one where the robot had to follow a track using reflectance sensors, and another where it had to race while avoiding obstacles and responding to collisions. I worked on the embedded C code for both parts, including the sensor readings for line following and bump sensor interrupts so the robot could detect and react to collisions. I also helped test the robot and fine-tune sensor thresholds to find a balance between speed and power efficiency.

    Embedded C · FSM · Sensors · Interrupts · Proportional Control · IoT
